Подключение как суперюзер:
```shell
MYSQL_PWD=StrongPass#2026 mysql -h0 -P9306 -uadmin
```
Создание\удаление\обновление пользователя(подключиться нужно как суперпользователь):
```shell
CREATE USER 'ingest' IDENTIFIED BY 'T-{H*)47YWd=!4qY';
DROP USER 'ingest';
SET PASSWORD '4?@2%_M=E*Og2NqM' FOR 'ingest';
```
Права:
```shell
read - читать данные из таблиц и выполнять операции с таблицами только на чтение.
write - записывать или удалять данные таблиц.
schema - создавать, изменять, удалять, импортировать, перечитывать или иным образом управлять схемами таблиц и серверными метаданными.
backup - выполнять серверные операции BACKUP.
replication - выполнять операции кластера репликации.
admin - управлять пользователями, токенами, правами и данными аутентификации.
```
